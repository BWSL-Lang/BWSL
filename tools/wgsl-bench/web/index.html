Method and limitations

The corpus includes SAXPY, unsigned hash, vector affine, a 25-tap RGBA Gaussian filter, four-bone skinning and four-light GGX shading. These are compute entry points; skinning and lighting here do not test the vertex/fragment pipeline. BWSL fixed-size work is explicitly unrolled because the native backend currently supports straight-line compute only.

Inputs are checked bit-for-bit before and after timing. Outputs are exact except GGX, which allows 0.0002 absolute + 0.0002 relative float error against a double-precision CPU formula. Both shader variants are also compared directly. NaN sentinels catch missing writes. Repeated dispatches overwrite the same output buffers, so this measures warm-buffer throughput.

Each sample pair runs both variants in randomized AB/BA order with a fixed seed. The JSON contains raw samples, paired bootstrap intervals, source hashes, compiler hash, browser details and exposed GPU information. A single browser/GPU and this small corpus cannot establish general parity.

The page uses normal browser settings. It does not disable timestamp quantization or require experimental flags. Keep this tab visible; backgrounding aborts the run.
